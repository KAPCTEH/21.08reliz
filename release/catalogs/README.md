# Подписанные каталоги обновлений

В этом каталоге хранятся только публичные, уже подписанные Ed25519 каталоги-кандидаты. Приватный ключ сюда не помещается.

- `internal.json` — внутренний канал.
- `staging.json` — приёмочный канал.
- `stable.json` — обычный выпуск 5%, 25% или 100%.
- `stable-rollback.json` — новый каталог с большей последовательностью и директивой `halt` либо `rollback`.

Старый каталог нельзя просто вернуть в активный ключ: защита клиента от понижения `catalog_sequence` его отвергнет. Для остановки или отката всегда создаётся новый подписанный документ с большей последовательностью.
