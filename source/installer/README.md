# Нативный Windows-установщик JustFun 7.8.3

Setup, Recovery и штатный Uninstall собираются NSIS 3.x как самостоятельные
Windows PE-файлы. Установочный контур не запускает PowerShell, CMD, BAT/CMD или
внешние сценарии.

## Гарантии установки

- единый дистрибутив для любых разрешённых компьютеров;
- стандартный путь программы заполняется автоматически;
- рабочие данные хранятся отдельно и не удаляются при обновлении;
- пользователь может изменить оба пути;
- распаковка выполняется во временный staging-каталог рядом с целевой папкой;
- старая установка заменяется только после проверки обязательных файлов;
- при ошибке старая установка и конфигурация восстанавливаются;
- после установки запускается встроенный smoke-тест Electron-приложения;
- создаются ярлыки рабочего стола, меню «Пуск», Recovery и штатный Uninstall;
- удаление рабочих данных требует явного выбора и подтверждённого маркера.

## Сборка

Сборка выполняется только на Windows:

```text
python build_windows.py \
  --payload-dir <payload> \
  --logo <official-logo.png> \
  --output-dir <output> \
  --node-modules <desktop-runtime/node_modules> \
  --makensis <makensis.exe>
```

Исходный официальный логотип и его прозрачный мастер проверяются по SHA-256 до
генерации ICO/BMP. Смена картинки или скрытая подмена бренда останавливает сборку.
