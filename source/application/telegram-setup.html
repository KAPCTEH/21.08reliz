Настройка Telegram

Защищённое подключение бота к рабочему пространству JustFun
Нужны два временных значения. Cloudflare API-токен применяется только во время развёртывания и не сохраняется. Токен Telegram сразу передаётся в защищённый Secret внутри Cloudflare Worker.
1. Создайте Cloudflare API-токен

Выберите один аккаунт. Права: Account → Workers Scripts → Edit, Account → D1 → Edit и Account → Account Settings → Read. Ограничьте ресурс одним своим аккаунтом.

2. Создайте Telegram-бота

Откройте @BotFather, выполните /newbot и скопируйте выданный токен.

После успешного подключения программа напомнит удалить этот токен в Cloudflare.
Значения не записываются в журнал, HTML-настройки, localStorage или обычные файлы. Окно использует отдельную временную сессию.
